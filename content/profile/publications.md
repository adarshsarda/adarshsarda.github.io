# Multimodal emotion detection publication

This record is the canonical portfolio note for the Springer paper and the applied-ML work
behind it. The published system combines speech and text signals with an LSTM-based
classifier and a voice-interactive workflow. My documented role is co-author and bachelor
project developer.

## Evidence boundary

Springer's public abstract reports approximately 86% accuracy for model-patient
conversational data. That number is retained as an attributed result. This portfolio does
not currently have the evaluation denominator, split, confidence interval, or an independent
reproduction, so the number should not be generalized into a clinical or cross-dataset
performance claim.
